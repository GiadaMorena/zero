OCR assets served by ZERO, loaded only when a receipt is read:
- Tesseract.js and Tesseract.js-core 7.0.0 from the pinned npm packages.
- Italian LSTM model from tesseract-ocr/tessdata_fast, commit in tessdata-source.txt.
- Original Apache 2.0 licenses are included alongside the assets.
The model and scripts contain no receipt/user data. Photos are processed in the browser; only the fields explicitly confirmed by the user are saved as a movement.
